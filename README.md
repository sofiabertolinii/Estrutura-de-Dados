# 📚 Estrutura de Dados — UFSM

Este repositório reúne os **trabalhos, exercícios e implementações práticas** desenvolvidos por mim na disciplina de **Estrutura de Dados** na Universidade Federal de Santa Maria (UFSM).

---

## 🧠 Conteúdo do repositório

Ao longo da disciplina, foram implementadas e estudadas diversas estruturas fundamentais da computação, incluindo:

### 📦 Estruturas lineares
- **Filas**
- **Filas de prioridade**
- **Deques**
- **Listas encadeadas**
- **Listas com alocação contígua**

### 🌳 Estruturas não lineares
- **Árvores binárias**
- **Tries (árvores de prefixo)**

---

## ⚙️ Objetivo

O objetivo do repositório é consolidar a prática dos principais conceitos de **Estruturas de Dados em C**, incluindo:

- Manipulação de memória
- Implementação de estruturas abstratas
- Uso de ponteiros e alocação dinâmica
- Aplicação de algoritmos sobre estruturas clássicas

---

## 🎯 Observação

Alguns projetos também envolvem a integração dessas estruturas em aplicações maiores, como editores de texto e jogos simples, reforçando o uso prático dos conceitos aprendidos.
